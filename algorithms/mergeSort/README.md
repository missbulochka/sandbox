# Merge sort

## Description

Merge is an efficient sort algorithm.
Efficiency in the best, average and worst case is **O(n log n)**.

## Algorithm

[Visualisation](https://www.toptal.com/developers/sorting-algorithms/merge-sort)

The merge sort method works on the principle of "divide & conquer":
1.  *Splitting* sequence into two subsequences of n/2 elements
2.  *Recursively* sort these subsequences by merge sort
3.  *Merge* two sorted subsequences
